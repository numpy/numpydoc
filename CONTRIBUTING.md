# Contributing to numpydoc

numpydoc is part of the NumPy project and follows its contribution guidelines and code of conduct.
See [Contributing to NumPy](https://numpy.org/devdocs/dev/index.html) for how to report issues, propose changes, and open pull requests.

numpydoc also follows [NumPy's AI policy](https://numpy.org/devdocs/dev/ai_policy.html).
If you use AI tools, you are responsible for reviewing and understanding all of the code you submit, and your pull request must say which tools you used and what they generated.
